# 위키

> 한 줄 정의: 여러 페이지가 **서로 링크로 이어진** 나만의 백과사전

## 내 말로 풀면
긴 글 한 편이 아니라, **개념 하나마다 짧은 페이지 하나**를 만들고 페이지끼리 링크로 연결하는 정리 방식이에요. 배울 때마다 계속 고치고 더해요.

## 비유하면
위키백과(Wikipedia)와 같아요. 글을 읽다가 모르는 단어를 누르면 그 단어 페이지로 넘어가요.

## 일반 메모와 다른 점

| | 일반 메모 | 위키 |
|---|---|---|
| 모양 | 긴 글 한 편 | 짧은 페이지 여러 개 |
| 단위 | 날짜나 주제 하나 | 개념 하나 = 페이지 하나 |
| 연결 | 따로따로 | 링크로 이어짐 |
| 쓰는 방식 | 한 번 쓰고 끝 | 계속 고치고 더함 |

## 예시
- 바로 이 `sponge-wiki`가 위키예요. 목차(README)에서 페이지로 넘어가요.
- 비슷한 말: **세컨드브레인**(두 번째 뇌) — 위키 방식으로 쌓아 두는 개인 노트
