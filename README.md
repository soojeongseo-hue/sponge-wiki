## ✏️ 이 위키 쓰는 규칙

| 규칙 | 설명 |
|---|---|
| 한 개념 = 한 페이지 | 페이지 하나에는 한 가지만 정리해요 |
| 내 말로 쓰기 | 설명을 그대로 옮기지 않고, 내가 이해한 말과 비유로 써요 |
| 링크 걸기 | 다른 페이지와 관련 있으면 링크로 이어요 |
| 목차에 추가 | 새 페이지를 만들면 이 목차에 한 줄 더해요 |
| 틀 쓰기 | 새 페이지는 [페이지 틀](_페이지틀.md)을 복사해서 시작해요 |
